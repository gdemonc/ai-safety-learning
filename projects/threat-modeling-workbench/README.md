# AI 威胁建模工作台

这个项目不是代码靶场，而是文档型工作台，用来把《AI Red 攻防指南》第 10 章的方法真正练一遍。

## 练习目标

选择一个 AI 项目，然后输出：

1. 架构图
2. 资产清单
3. 信任边界
4. 攻击面清单
5. 假设登记表
6. 修复建议

## 推荐对象

- 你自己的 `rag-security-lab`
- 一个开源 RAG 项目
- 一个开源 Agent 项目
- 一个接了 MCP 工具的项目

## 目录说明

- `templates/`：你可直接复用的文档模板
- `cases/`：未来每个被分析项目放一个子目录
