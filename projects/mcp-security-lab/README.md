# MCP / 工具安全实验室

这个项目用来练“模型从会说到会做”之后的安全问题。

## 练习目标

完成这个实验后，你应该能解释：

1. 为什么工具元数据本身就是攻击面
2. 为什么 MCP 的风险重点在权限、路径和审计
3. 为什么工具输出链会放大风险
4. 为什么渲染型工具会带来额外信任问题

## 建议最小工具集

建议你实现 3 个本地 mock 工具：

- `fs_read`：读取限定目录内文件
- `notes_store`：保存笔记
- `db_query_mock`：读取本地假数据

## 建议实验主题

1. 工具描述投毒
2. 路径边界测试
3. 工具权限最小化
4. 工具调用审批
5. 工具调用日志与追溯

## 目录说明

- `app/`：MCP 实验代码或模拟器
- `fixtures/`：受限目录、假数据库、假笔记文件
- `prompts/`：测试分类
- `notes/`：记录模板
