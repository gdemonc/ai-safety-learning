# Agent 记忆安全实验室

这个项目专门练长期记忆风险。

目标是让你真正理解：

- 为什么记忆投毒像二阶注入
- 为什么 AI 的持久化常常不在进程，而在数据
- 为什么“写入时看起来无害”的内容会在未来产生风险

## 练习目标

完成这个实验后，你应该能解释：

1. 会话内记忆和长期记忆的差别
2. 哪些内容不应该被自动写入长期记忆
3. TTL、来源标记、审批写入为什么重要
4. 记忆为什么会形成跨会话风险

## 建议实现方式

做一个最小记忆 Agent：

- 一个基础问答能力
- 一个长期记忆存储层
- 一条“是否写入记忆”的判断逻辑
- 一个“读取记忆回答问题”的逻辑

存储可以很简单：

- `sqlite`
- `json`
- `chroma`

## 建议实验主题

1. 普通事实写入
2. 建议型内容写入
3. 链接型内容写入
4. 操作说明写入
5. 跨会话触发复现
